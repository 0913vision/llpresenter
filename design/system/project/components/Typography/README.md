# Typography

The M3 live-check proposal increases the general UI scale by one step. The
project README is the current size reference for every component. Component
examples use the named `type-*` tokens, including lists, labels and menus.

| Role | Before | Proposed |
| --- | --- | --- |
| Heading | 18/24 | 20/28 |
| Title, body, strong body, panel tabs, bands, strong captions | 14/20 | 16/22 |
| Labels, captions, toolbar names | 12/16 | 14/20 |
| LIVE micro badge | 12/16 | 12/16 |
| Output and thumbnail lyrics | Output-relative | Unchanged |

Weights and Pretendard remain unchanged. Single-line rows stay 30px, menu rows
28px, small controls 26px and medium controls 30px. A two-line row grows to
52px to hold 22px + 2px + 20px with breathing room. Count badges and keycaps
grow to 22px. Do not reduce fonts to fit the minimum 1280x720 window. Ellipsize
long names with their existing tooltip, and scroll lists vertically.

The gallery shows the token scale and representative controls. Existing
component cards retain their hover, selected, disabled and focus specimens
using this scale. The app check covers real service rows, menus, labels and
dialogs at the minimum window size.
