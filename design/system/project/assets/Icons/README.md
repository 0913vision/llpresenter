These icons come from Phosphor Icons (phosphoricons.com, MIT license) in the Regular weight. Only two, play and pause, use the Fill weight.

Each file is drawn in one ink (`currentColor`). Shown with `<img>`, an icon appears black and you can't change its color, so in the app, paint it as a mask so that it follows the text color (`<span class="ll-i ll-i-14 ll-i-song"></span>`). For sizes, follow the Icons section of the README.
