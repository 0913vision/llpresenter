Phosphor Icons(phosphoricons.com, MIT 사용권)의 Regular 굵기에서 가져온 아이콘입니다. 재생과 일시정지 두 개만 Fill 굵기입니다.

각 파일은 한 가지 잉크(`currentColor`)로 그려져 있습니다. `<img>`로 보이면 검정으로 보이고 색을 바꿀 수 없으므로, 앱에서는 마스크로 칠해 글자색을 따르게 합니다(`<span class="ll-i ll-i-14 ll-i-song"></span>`). 크기는 README의 아이콘 항목을 따릅니다.
