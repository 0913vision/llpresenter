# M3 UX screenshot index

Unedited CDP captures for [m3-ux-pass.md](../m3-ux-pass.md). Snapshot

window/capture size. The Bible follow-up, clipboard-reader and Look-dependency
fixtures are disclosed in the report; original sample failure is separate. All
text in the sample is invented QA material, not an external song or Bible.

The images show observations, including empty interfaces and unavailable
controls. Presence in this index does not mean the feature passed. The report
contains results, reproduction steps, severity and owner. Both recovery runs
were deliberately induced test conditions. No screenshots of an incorrectly
selected dialog or a missed transient saving frame are published.
