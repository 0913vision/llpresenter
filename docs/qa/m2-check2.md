# M2 두 번째 앱 확인 안내

점검용 태그는 `m2-check2`입니다. 담당자가 태그 게시를 알린 뒤 시작합니다. 변경점
확인에 10~15분, 연속 출력에 60분, 연결과 재시작 확인에 약 10분을 잡습니다. 이번
확인은 진행 화면과 본 화면 출력을 중심으로 합니다.

## 새 복사본으로 실행합니다

첫 점검에서 사용한 Git과 Node.js, npm이 있는 Windows에서 PowerShell을 엽니다. 새
폴더에 이번 태그를 받습니다.

```powershell
git clone --branch m2-check2 https://github.com/0913vision/llpresenter llpresenter-m2-check2
Set-Location -LiteralPath .\llpresenter-m2-check2
npm ci
```

이번 태그의 샘플을 저장소 밖의 새 데이터 폴더에 복사합니다. 이미 같은 이름의
폴더가 있으면 다른 이름을 지정합니다. `app.json`과 `LoveLight`가 함께 있는
폴더가 `LLP_USER_DATA`가 됩니다.

```powershell
$sampleData = Join-Path $env:LOCALAPPDATA 'LoveLight-m2-check2'
if (Test-Path -LiteralPath $sampleData) {
  throw '이미 있는 데이터 폴더입니다. 새 폴더 이름을 지정합니다.'
}
Copy-Item -LiteralPath .\docs\qa\m2-check\sample -Destination $sampleData -Recurse
$env:LLP_USER_DATA = $sampleData
npm run build
npm run preview
```

같은 PowerShell에서 실행합니다. 샘플 원본 폴더를 직접 지정하지 않습니다. 첫 점검
데이터 대신 이번 샘플의 새 복사본을 사용해야 둘째 곡의 배경 지정도 반영됩니다.
다시 실행할 때도 같은 PowerShell에서 `npm run preview`를 실행합니다.

`샘플 주일 예배`가 열리는지 확인합니다. `새벽을 여는 노래`는 10개 슬라이드,
`빛 가운데 걷는 길`은 5개, `평안의 저녁`은 3개입니다. 첫째와 둘째 곡은 같은 12초
반복 영상, 셋째 곡은 노을 이미지를 배경으로 사용합니다.

## 첫 점검에서 달라진 부분을 확인합니다

먼저 `새벽을 여는 노래`를 선택하고 첫 슬라이드를 클릭합니다. 위쪽 `본 화면`
출력을 켭니다.

- **용어:** 화면의 `장` 표기가 `슬라이드`로 바뀌었는지 확인합니다.
- **포커스:** 진행의 슬라이드와 예배 순서 행을 키보드로 옮길 때 파란 포커스
  테두리가 겹치지 않는지 확인합니다. 출력 중인 슬라이드의 빨간 테두리는
  유지됩니다.
- **Ctrl Z:** F2로 가사를 지운 뒤 Ctrl Z를 눌러도 가사가 복구되지 않아야 합니다.
  슬라이드를 다시 클릭해 가사를 출력합니다.
- **미리보기 B:** 아래의 본 화면, 무대 화면, 방송 자막 순서가 고정되고, 클릭한
  화면이 위에서 크게 보이며 해당 칸에 선택 표시가 나타나야 합니다.
- **예배 순서 제목 A:** 왼쪽 패널 제목에 `샘플 주일 예배`가 더 크게 보이는지
  확인합니다.
- **글자 크기:** 본문과 작은 이름표, 화면 이름을 첫 점검보다 읽기 편한지
  확인합니다.
- **UI 확대:** Ctrl +, Ctrl -, Ctrl 0으로 조작 화면을 확대하고 초기화합니다.
  100~200%에서 10%p씩 바뀌며, 본 화면 출력의 글자 크기와 해상도는 유지돼야
  합니다. `+` 키 대신 Ctrl =도 사용할 수 있습니다.
- **슬라이드 크기:** 아래 크기 슬라이더가 부드럽게 움직이는지 확인하고, 옆의 `%`
  입력에 `125`를 입력한 뒤 Enter를 누릅니다. 50~200% 범위이며 `100`으로 돌아올
  수 있습니다. 이 값은 창 크기 구간별로 기억됩니다.
- **이미지 배경:** `평안의 저녁`의 슬라이드를 누르면 노을 이미지 위에 가사가
  나타나야 합니다.
- **곡 배경:** 첫째 곡으로 돌아오면 반복 영상이 적용되고, 같은 영상인 둘째
  곡으로 옮겨도 영상이 처음부터 다시 시작하지 않아야 합니다.

미리보기 전환은 실제 출력 대상을 바꾸지 않습니다. 작은 화면의 선택 표시와
입력란의 테두리는 슬라이드 및 예배 순서 행의 포커스 표시와 별개입니다.

## 실제 모니터에서 남은 항목을 확인합니다

### 1. 두 모니터에서 60분 연속 출력합니다

1. Windows에서 두 모니터를 확장 모드로 사용합니다. 앱 조작 창은 주 모니터에
   두고, `본 화면`을 켰을 때 두 번째 모니터에 전체 화면으로 나오는지 확인합니다.
2. `새벽을 여는 노래`의 첫 슬라이드를 클릭해 가사와 반복 영상이 함께 보이는지
   확인하고 시작 시각을 적습니다.
3. 60분 동안 출력을 켜 둡니다. 1~2분마다 슬라이드를 바꿉니다. 마지막에서는 처음
   슬라이드를 다시 누르거나, 같은 영상인 `빛 가운데 걷는 길`로 옮깁니다. 시작과
   끝에는 두 번째 모니터의 영상 반복 지점을 직접 봅니다.
4. 영상이 검게 번쩍이거나 멎는지, 슬라이드를 바꿀 때 눈에 띄게 끊기는지
   확인합니다. 정상 기대는 60분 동안 내용이 계속 출력되고 반복 지점에서도 눈에
   보이는 끊김이 없는 것입니다.

작업 관리자의 **세부 정보**에서 명령줄 열을 표시하고, 점검용 데이터 폴더가
`--user-data-dir`에 들어 있으며 `--type=gpu-process`가 붙은 `electron.exe`를
찾습니다. 이것이 이번 앱의 GPU 프로세스입니다. 시작과 60분 뒤의 PID와 메모리를
적습니다. 가능하면 30분에도 적습니다.

메모리는 같은 열을 사용하며, `커밋 크기`를 표시할 수 있으면 그 값을 기록합니다.
열 이름과 단위도 그대로 적습니다. 값이 오르내리는지, 시간이 지날수록 계속
높아지는지도 봅니다. 정상 기대는 GPU 프로세스의 메모리가 지속적으로 증가하지
않는 것입니다. 이 항목은 아직 확인 중이므로 수치와 출력 상태를 함께 전달합니다.

### 2. 출력 중 두 번째 모니터를 분리했다가 다시 연결합니다

1. 가사와 영상이 출력되는 상태에서 두 번째 모니터의 케이블을 분리합니다.
2. 기본 설정의 사양상 기대는 같은 출력이 조작 모니터의 별도 창으로 옮겨지고,
   가사와 영상 재생이 이어지는 것입니다. 앱이 종료되거나 내용이 사라지면 발생
   시각을 기록합니다. 경고 표시가 바뀌는지도 확인합니다.
3. 같은 모니터를 다시 연결합니다. 같은 내용이 두 번째 모니터의 전체 화면으로
   자동 복귀해야 합니다. 연결 후 화면이 돌아오기까지 걸린 시간도 적습니다.

화면 연결 알림 카드는 아직 조작 화면에 연결되지 않은 부분입니다. 카드 유무와
함께 실제 출력 창의 이동, 내용 유지, 전체 화면 복귀를 기록합니다.

### 3. 앱을 강제 종료하고 같은 데이터로 다시 실행합니다

1. 출력 중인 곡과 슬라이드 번호, 배경을 적습니다. 작업 관리자에서 이번 점검용 앱
   그룹에 **작업 끝내기**를 실행합니다. 개발 실행에서는 LoveLight Presenter 대신
   Electron으로 보일 수 있습니다. 그룹을 펼쳐 조작 창 제목을 확인한 뒤 해당
   그룹을 종료합니다. 조작 창과 출력 창이 모두 닫혔는지 확인합니다.
2. 같은 PowerShell에서 `npm run preview`로 다시 실행합니다.
3. 사양상 같은 예배 순서가 열리고, 출력은 꺼진 대기 상태에서 `출력 상태 복구`
   대화상자가 떠야 합니다. `복구`를 선택하면 선택한 출력, 마지막 슬라이드와
   배경이 돌아와야 하며, `새로 시작`은 비어 있는 출력 상태로 시작해야 합니다.
4. **현재 로컬 점검에서는 복구 대화상자가 나타나지 않았고, 마지막 가사와 배경이
   비어 있었습니다. 이 부분은 통과로 처리하지 않습니다.** 이번 빌드에서도
   같은지, 예배 순서는 열리는지, 출력이 꺼져 있는지 기록합니다.

복구 대화상자가 없으면 그 사실을 먼저 적은 뒤, 슬라이드를 다시 클릭하고 본 화면
출력을 켜서 수동으로 진행을 재개할 수 있습니다.

## 현재 범위를 확인합니다

- 메뉴와 준비 편집에는 아직 연결되지 않은 부분이 있습니다. 이번에는 진행을
  중심으로 확인합니다.
- 무대 화면과 방송 자막은 미리보기 전환을 확인합니다. 별도 출력과 무대 구성은
  이번 본 화면 출력 확인의 범위에 포함하지 않습니다.
- `되돌림` 단추(툴팁: `되돌리기`)는 현재 보입니다. 기본 숨김과 표시 설정은 아직
  연결되지 않았지만 Ctrl Z로 지우기를 되돌리는 동작은 제거됐습니다.
