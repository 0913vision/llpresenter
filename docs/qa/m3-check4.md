# M3 앱 확인 안내

약 40분 동안 확인합니다. 전달받은 점검 태그로 앱을 설치하고, 아래 샘플을 별도
폴더에 복사해 사용합니다. 확인하지 못한 항목은 통과로 표시하지 않습니다.

## 설치하고 실행합니다

Windows에서 Git과 프로젝트에 필요한 Node.js, npm을 준비한 뒤 PowerShell을
엽니다. 기존 개발 폴더와 다른 새 폴더에서 실행합니다. 첫 질문에는 전달받은 점검
태그를 그대로 입력합니다.

```powershell
$checkTag = Read-Host '전달받은 점검 태그'
if ([string]::IsNullOrWhiteSpace($checkTag)) {
  throw '점검 태그가 필요합니다.'
}
git clone --branch $checkTag --single-branch https://github.com/0913vision/llpresenter llpresenter-check4
if ($LASTEXITCODE -ne 0) { throw '점검 태그를 가져오지 못했습니다.' }
Set-Location -LiteralPath .\llpresenter-check4
git fetch --no-tags origin docs/qa/m3-check4-remaining
if ($LASTEXITCODE -ne 0) { throw '점검 자료를 가져오지 못했습니다.' }
git restore --source=FETCH_HEAD --worktree -- docs/qa/m3-check4/sample docs/qa/m3-check4/import-sections.txt
if ($LASTEXITCODE -ne 0) { throw '점검 자료를 준비하지 못했습니다.' }
npm ci
if ($LASTEXITCODE -ne 0) { throw '설치에 실패했습니다.' }

$sampleData = Join-Path $env:LOCALAPPDATA 'LoveLight-check4'
if (Test-Path -LiteralPath $sampleData) {
  throw '이미 있는 데이터 폴더입니다. 새 폴더 이름을 지정합니다.'
}
Copy-Item -LiteralPath .\docs\qa\m3-check4\sample -Destination $sampleData -Recurse
$env:LLP_USER_DATA = $sampleData
npm run build
if ($LASTEXITCODE -ne 0) { throw '빌드에 실패했습니다.' }
npm run preview
```

복사본에는 `app.json`, `bible`, `LoveLight`가 함께 있습니다. 다시 실행할 때는
같은 PowerShell에서 `npm run preview`를 실행합니다. 샘플 원본은 직접 편집하지
않습니다.

성경 샘플은 실제 성경 본문이 아닌 창작 점검 문장입니다. 주소 입력을 확인하도록
요한복음의 위치만 들어 있습니다. 곡과 텍스트 가져오기 자료도 창작 점검
문장입니다.

## 40분 동안 확인합니다

시간은 앱을 연 뒤부터 셉니다. 본 화면과 무대 화면은 처음에 별도 창으로 설정돼
있고 출력은 꺼져 있습니다. 창이 작업을 가리면 위쪽 출력 버튼으로 끕니다.

| 시간    | 조작                                                                                                                                                                      | 확인할 내용                                                                                                                                                                          |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 0~5분   | 준비에서 첫 곡을 선택하고 `라이브러리 곡 편집`을 엽니다. 제목 끝에 `점검`을 더하고 Enter를 누릅니다. 다른 곡을 선택한 뒤 다시 엽니다.                                     | 기존 곡의 가사와 구성은 유지되고 바꾼 제목이 남습니다. 이 샘플의 곡은 이전 형식으로 준비되어 첫 저장 때 새 형식으로 바뀝니다.                                                        |
| 5~10분  | 진행에서 첫 곡의 `주일용` 구성을 열고 슬라이드를 차례로 클릭합니다. F2를 두 번 누르고 F1도 두 번 누릅니다.                                                                | 열 개 슬라이드가 구성 순서대로 출력되며 반복 구간도 다시 나옵니다. 같은 지우기 키를 다시 누르면 지운 내용이 돌아옵니다.                                                              |
| 10~15분 | `파일` 메뉴에서 텍스트 파일 가져오기를 열고 점검 자료의 `import-sections.txt`를 선택합니다. `줄 바꿈`과 한 슬라이드에 2줄을 선택하고 미리본 뒤 `편집`, `저장`을 누릅니다. | 네 슬라이드가 두 구간으로 보입니다. 각 구간의 첫 슬라이드에만 이름표가 보이고 저장한 곡이 라이브러리에 나타납니다.                                                                   |
| 15~20분 | 준비의 항목 추가에서 성경 구절을 선택해 `요`와 Tab, `1:1-2`를 입력해 추가합니다. 진행의 성경 칸에서 `요`와 Tab, `3:16-18`을 입력하고 `예배 순서에 넣기`를 누릅니다.       | 선택한 예배 구간에 성경 항목이 들어갑니다. 추가하는 동안 현재 출력은 바뀌지 않고 최근 구절에 주소가 남습니다.                                                                        |
| 20~25분 | 진행의 `타이머` 탭에서 `점검 1분`을 시작하고 일시 정지합니다. 행을 우클릭해 이름을 바꾸고, 다시 우클릭해 삭제합니다. 삭제 확인을 한 번 취소한 뒤 다시 열어 삭제합니다.    | 이름이 연결된 퀵 실행에도 바뀝니다. 취소하면 그대로 남고, 삭제하면 연결된 퀵 실행 항목도 사라집니다. 다른 출력 내용은 유지됩니다.                                                    |
| 25~29분 | 미디어를 열어 동영상과 이미지를 선택합니다. 화면 설정에서 Look의 가사 스타일 글꼴 목록을 열고 설치된 글꼴을 검색해 선택한 뒤 지원하는 굵기를 고릅니다.                    | 미디어 미리보기와 속성이 선택한 항목을 따릅니다. 글꼴과 굵기가 저장되고 해당 화면의 출력에 반영됩니다.                                                                               |
| 29~34분 | 화면 설정의 `현재와 다음` 무대 배치를 우클릭해 복제하고 복제본 이름을 바꿉니다. 복제본의 요소를 다른 요소 가까이 끌면서 Alt를 눌렀다 놓습니다.                            | 복제본은 원본과 별도로 수정됩니다. 안내선이 나타나며 Alt를 누르는 동안 정렬이 풀리고 놓으면 다시 정렬됩니다.                                                                         |
| 34~38분 | 실제 두 번째 화면이 있으면 화면 설정에서 본 화면을 선택해 해당 모니터와 전체 화면을 지정합니다. `모니터 번호 표시`, `테스트 패턴`, 항상 위 설정을 확인합니다.             | 번호 카드가 어느 화면에 나타나는지, 테스트 패턴이 선택한 화면에 보이는지, 전체 화면 위 상태가 기대대로 유지되는지 직접 확인합니다. 두 번째 화면이 없으면 확인하지 못함으로 적습니다. |
| 38~40분 | 준비에서 예배 항목의 메모를 바꾸고 출력을 모두 끕니다. 정상 종료한 뒤 같은 PowerShell에서 다시 실행해 메모와 가져온 곡을 확인합니다.                                      | 앱이 정상 종료되고 다시 연 뒤 메모와 곡의 두 구간이 남습니다. 저장이 빠르면 `저장 중` 대화상자는 나타나지 않을 수 있습니다.                                                          |

## 알려진 문제와 확인하지 못한 항목

- M3-C4-7: 무대 배치의 숫자를 입력한 직후 작업 공간을 키보드 단축키로 바꾸면
  입력 중인 값이 사라질 수 있습니다. 단축키를 누르기 전에 Enter로 확정합니다.
- M3-C4-8: 무대 요소의 너비를 아주 작게 줄일 때 드래그와 숫자 입력의 최소값이
  다릅니다. 너비는 숫자 칸에 20 이상으로 입력합니다.
- M3-C4-6: 무대 배치가 있는데도 앱 기록에 배치를 찾지 못했다는 경고가 잠깐 남을
  수 있습니다. 실제 무대 출력에 문제가 보이면 함께 기록합니다.
- 실제 두 번째 화면의 위치, 번호 카드, 전체 화면의 항상 위 상태와 `저장 중`
  대화상자는 사용자만 확인할 수 있습니다. 보이지 않았거나 장비가 없으면 확인하지
  못함으로 적습니다.
- 테스트 중 파일을 잠그거나 저장 오류를 일부러 만들지 않습니다. 예상치 못한 저장
  오류가 보이면 내용과 시각을 기록합니다.
