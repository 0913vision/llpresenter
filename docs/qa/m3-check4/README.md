# Check4 sample

`sample` is a portable starting data folder. Copy it before opening the app. It
contains one sample service, three invented songs, one template, a timer,
quick-run items, two original procedural media files and a sample Bible index.
The Bible sentences are invented and are not Scripture. The songs start in the
version 1 format so the first edit can exercise grouped-song migration.

The main and stage screens use window output; the broadcast screen uses a
capture window. All three start with always-on-top off and without saved monitor
assignments. The sample service and its contents use stable fixture IDs; the app
creates its normal default Look and stage layout when needed.

`import-sections.txt` is a separate invented text-import fixture. Its two
labeled sections have four lines each, so two lines per slide produce four
slides in two groups. The copied data folder changes during a check; keep the
tracked sample unchanged.
