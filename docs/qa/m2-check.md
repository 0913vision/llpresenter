# M2 앱 확인 안내

진행 화면을 약 30분 동안 확인하는 안내입니다. 점검용 태그는 `m2-check1`입니다.
담당자가 태그 게시를 알린 뒤 시작합니다.

## 설치하고 실행합니다

Git과 프로젝트에서 사용하는 Node.js, npm이 설치된 Windows에서 PowerShell을
엽니다. 기존 개발 폴더와 다른 새 폴더를 사용합니다.

```powershell
git clone --branch m2-check1 https://github.com/0913vision/llpresenter llpresenter-m2-check1
Set-Location -LiteralPath .\llpresenter-m2-check1
npm ci
```

다음 명령은 샘플을 저장소 밖의 새 사용자 데이터 폴더에 복사합니다. 이미 같은
이름의 폴더가 있으면 날짜나 번호를 붙여 다른 이름을 사용합니다. `app.json`과
`LoveLight`가 함께 들어 있는 폴더를 지정해야 합니다.

```powershell
$sampleData = Join-Path $env:LOCALAPPDATA 'LoveLight-m2-check1'
if (Test-Path -LiteralPath $sampleData) {
  throw '이미 있는 데이터 폴더입니다. 새 폴더 이름을 지정합니다.'
}
Copy-Item -LiteralPath .\docs\qa\m2-check\sample -Destination $sampleData -Recurse
$env:LLP_USER_DATA = $sampleData
npm run build
npm run preview
```

같은 PowerShell에서 실행해야 `LLP_USER_DATA`가 적용됩니다. 샘플 원본 폴더를 직접
지정하지 않습니다. 앱의 데이터, 로그, 백업은 복사한 폴더에 생깁니다. 다시 실행할
때도 해당 PowerShell에서 `npm run preview`를 실행합니다.

## 30분 동안 확인합니다

| 시간    | 조작                                                                                                                        | 확인할 내용                                                                                                                                                                |
| ------- | --------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0~3분   | 진행 화면과 왼쪽 예배 순서를 확인합니다.                                                                                    | `샘플 주일 예배`가 열리고, `경배와 찬양`, `새벽을 여는 노래`, `빛 가운데 걷는 길`, `말씀 후 찬양`, `평안의 저녁` 순서로 보입니다.                                          |
| 3~8분   | `새벽을 여는 노래`를 선택한 뒤 장을 클릭합니다. 다른 곡도 선택합니다.                                                       | 첫 곡은 `주일용` 구성의 10장, 둘째 곡은 5장, 셋째 곡은 3장입니다. 장을 클릭하면 가사가 미리보기에 즉시 나타납니다. 선택한 곡과 출력 중인 곡의 표시가 구분됩니다.           |
| 8~12분  | 장을 출력한 뒤 Space, →, Page Down, ←, Page Up을 누릅니다.                                                                  | 앞의 세 키는 다음 장, 뒤의 두 키는 이전 장을 출력합니다. 마지막 장에서 다음 키를 눌러도 다음 곡으로 넘어가지 않습니다.                                                     |
| 12~17분 | 첫 곡을 출력한 상태에서 Ctrl ↓ 두 번, Ctrl ↑ 한 번, Ctrl L을 누릅니다. 장 격자와 예배 순서에 각각 포커스를 두고 반복합니다. | 열리는 곡은 `빛 가운데 걷는 길`, `평안의 저녁`, `빛 가운데 걷는 길`, `새벽을 여는 노래`입니다. 구분 제목은 건너뜁니다. 이 키들만으로 출력 가사가 바뀌지는 않습니다.        |
| 17~21분 | 작은 무대 화면 및 방송 자막 미리보기의 그림을 클릭합니다. 본 화면 그림도 클릭합니다.                                        | 클릭한 화면이 큰 미리보기로 바뀝니다. 실제 출력은 바뀌지 않습니다.                                                                                                         |
| 21~25분 | 지우기 줄의 가사 지우기와 되돌리기를 누릅니다. F2 후 Ctrl Z, F1 후 Ctrl Z도 시도합니다.                                     | 가사가 사라졌다가 돌아옵니다. F1은 전체 지우기입니다. 소품, 오디오, 메시지 등이 비어 있으면 해당 지우기 버튼에는 눈에 보이는 변화가 없습니다.                              |
| 25~28분 | 위쪽 본 화면 출력을 켜고 끕니다. 다시 켭니다.                                                                               | 본 화면 출력 창이 열리고 닫히며, 다시 켜면 현재 가사가 나타납니다. 모니터가 하나이면 별도 창으로 열립니다. 두 번째 모니터가 있으면 그 화면에 가사가 나타나는지 확인합니다. |
| 28~30분 | 창 크기를 줄이고 늘린 뒤 종료하고 다시 실행합니다.                                                                          | 글자나 버튼이 겹치거나 잘리지 않는지 확인합니다. 같은 예배 순서가 다시 열리는지 확인합니다.                                                                                |

## 아직 완성되지 않은 부분을 확인합니다

- 메뉴를 눌러도 메뉴가 열리지 않습니다. 메뉴를 통해 파일을 여는 대신 위의 샘플
  복사 방법을 사용합니다.
- 준비 작업 공간에서 곡이나 예배 순서를 편집하는 기능은 아직 사용할 수 없습니다.
  이번에는 진행 화면을 확인합니다.
- 샘플에는 반복 영상과 이미지가 포함되어 있습니다. 현재 진행 화면에서 곡을
  클릭하는 것만으로 곡의 배경이 자동 출력되지는 않습니다. 배경을 고르는 UI도
  아직 연결되지 않아 가사 확인은 검은 배경으로 진행합니다.
- 무대 화면과 방송 자막은 미리보기 전환만 확인합니다. 각 화면의 전용 출력과 무대
  화면 구성은 아직 완성되지 않았습니다.
- 큰 미리보기로 고른 화면은 앱을 다시 실행하면 본 화면으로 돌아갑니다.
- 이미지 파일은 정상적으로 읽히지만 현재 출력 렌더러에서는 배경으로 표시되지
  않습니다. 모니터가 하나이면 본 화면 출력은 별도 창으로 열리며, 연결할 두 번째
  모니터가 없다는 경고가 표시될 수 있습니다.
- M2-5: 영상이 반복되는 동안 메인 프로세스의 메모리 사용량이 크게 오르내릴 수
  있습니다. 이번 짧은 확인으로 장시간 안정성이 검증되는 것은 아닙니다.

## 발견한 내용을 전달합니다

이상한 동작마다 아래 양식으로 적습니다. 가능하면 화면 사진과 `LLP_USER_DATA`
폴더 안의 `logs/main.log`를 함께 전달합니다.

```text
버전: m2-check1
한 일: 어느 곡의 몇 번째 장에서 어떤 버튼이나 키를 눌렀는지 적습니다.
예상: 기대한 동작을 적습니다.
실제: 실제로 나타난 동작과 다시 해도 같은지 적습니다.
Windows 디스플레이 배율: 예) 100%, 125%, 150%
모니터: 개수와 해상도를 적습니다.
앱 창 크기: 예) 최대화, 약 1600x900
발생 시각:
사진 또는 로그:
```

설치나 실행이 실패하면 실패한 명령과 PowerShell의 오류 내용을 전달합니다.
