# M3 앱 확인 안내

약 40분 동안 확인하는 안내입니다. 실행할 태그는 `m3-check2`입니다. 2026년 10월
26일 21시 무렵에 사용자가 편한 시간에 시작합니다.

현재는 준비본입니다. `m3-check2`는 아직 게시되지 않았으며, 아래 기능 목록은
`m3-check1`의 실제 점검 결과를 바탕으로 작성했습니다. 새 태그가 게시되면 QA가
다시 실행해 이 문서와 [점검 결과](m3-check/smoke.md)를 갱신합니다.
`m3-check1`에는 저장 실패 후 종료할 때 편집을 잃는 문제가 있어 사용하지
않습니다.

## 설치하고 실행합니다

Git과 프로젝트에서 사용하는 Node.js, npm이 설치된 Windows에서 PowerShell을
엽니다. 기존 개발 폴더와 다른 새 폴더를 사용합니다. `m3-check2` 태그가 게시된 뒤
다음 명령을 실행합니다.

샘플은 앱 태그 이후에 작성되는 점검 자료에서 가져옵니다. `git restore`는 아래의
점검 자료 경로에만 적용합니다. 앱 소스는 `m3-check2` 태그를 유지합니다.

```powershell
git clone --branch m3-check2 --single-branch https://github.com/0913vision/llpresenter llpresenter-m3-check2
Set-Location -LiteralPath .\llpresenter-m3-check2
git fetch --no-tags origin docs/qa/m3-check
git restore --source=FETCH_HEAD --worktree -- docs/qa/m3-check
npm ci
```

다음 명령은 샘플을 저장소 밖의 새 사용자 데이터 폴더에 복사합니다. 같은 이름의
폴더가 이미 있으면 날짜나 번호를 붙여 새 이름을 지정합니다. `app.json`, `bible`,
`LoveLight`가 함께 있는 폴더를 `LLP_USER_DATA`로 지정해야 합니다.

```powershell
$sampleData = Join-Path $env:LOCALAPPDATA 'LoveLight-m3-check2'
if (Test-Path -LiteralPath $sampleData) {
  throw '이미 있는 데이터 폴더입니다. 새 폴더 이름을 지정합니다.'
}
Copy-Item -LiteralPath .\docs\qa\m3-check\sample -Destination $sampleData -Recurse
$env:LLP_USER_DATA = $sampleData
npm run build
npm run preview
```

같은 PowerShell에서 실행해야 `LLP_USER_DATA`가 적용됩니다. 샘플 원본을 직접
지정하지 않습니다. 앱의 로그와 백업은 복사한 폴더에 생깁니다. 다시 실행할 때도
해당 PowerShell에서 `npm run preview`를 실행합니다.

성경 패널 점검용 자료는 **실제 성경 본문이 아닙니다**. 역본 이름과 모든 문장에
창작 점검 자료라는 표시가 있습니다. `요 3:16-18`처럼 주소를 입력하는 동작만
확인하며, 요한복음의 위치만 들어 있습니다. 찬양 가사도 모두 점검용 창작문입니다.

## 이번에 확인할 기능을 알아봅니다

새 예배를 틀이나 지난 예배에서 만들고, 가져올 항목을 고를 수 있습니다. 준비에서
메모와 이번 예배의 배경을 바꾸며, 항목 추가로 빈 자리에 곡을 넣을 수 있습니다.
진행에는 성경 주소 입력과 성경 슬라이드 패널, 저장된 퀵 실행 항목이 있습니다.
화면 설정에는 화면 목록과 Look 목록, 무대 배치 목록, 모니터 배치가 있습니다.

`m3-check2`의 화면 속성, 무대 화면 배치, 미디어 보기, 퀵 실행 이름 변경과 삭제의
포함 여부는 태그 게시 후 확인해 이 안내에 반영합니다.

## 40분 동안 확인합니다

아래 표의 시간은 앱이 열린 뒤부터 셉니다. 출력 창은 실제 화면에 나타납니다.
샘플의 본 화면은 별도 창이며 항상 위 설정이 켜져 있습니다. 무대 화면도 별도
창이지만 항상 위 설정은 꺼져 있습니다. 출력 창이 작업을 가리면 위쪽의 본 화면과
무대 출력 버튼으로 끕니다.

미디어 패널이 보이지 않으면 위쪽 `미디어` 버튼을 누릅니다.

## 현재 사용할 수 없는 부분과 알려진 문제를 확인합니다

다음은 `m3-check1`에서 확인한 상태입니다. `m3-check2`의 실제 포함 여부와 수정
결과는 게시 후 점검해 갱신합니다.

- 화면 속성 편집과 무대 배치 편집기는 연결되지 않았습니다. 목록과 모니터 배치만
  볼 수 있습니다. 무대의 전용 현재 및 다음 가사 배치도 이번 확인에서는
  제외합니다.
- 미디어 `가져오기` 버튼은 비활성 상태입니다. 영상 가져오기, 재생 불가능한
  파일의 거절, 파일 크기 표시를 사용자가 UI에서 확인할 수 없습니다. QA는 별도
  백엔드 점검에서 12초 영상의 1,123,968바이트와 1280×720 해상도를 확인했고,
  재생할 수 없는 파일의 목록 추가가 거절되는 것을 확인했습니다.
- 퀵 실행의 이름 변경과 삭제는 `m3-check1` 이후 변경입니다. `검은 화면`은
  `m3-check1`에서 비활성 상태입니다.
- 예배 순서의 항목 추가에는 성경 구절을 직접 넣는 기능이 아직 없습니다. 위 표의
  성경 확인은 퀵 실행의 주소 입력과 저장된 성경 항목을 사용합니다.
- M3-C1-1은 저장 실패 후 일반 닫기로 종료하면 최신 메모를 잃는 문제입니다.
  `m3-check2`는 이 수정이 포함될 예정이며 QA의 재점검 결과를 반영할 예정입니다.
  파일을 잠근 상태에서 닫는 시험은 하지 않습니다. `저장할 수 없음`이 보이면
  내용을 기록하고 `강제로 닫기`를 누르지 않습니다.
- M3-C1-2는 정상 종료 때 정리 과정에서 오류가 로그에 기록되는 문제입니다.
  M3-C1-1과 함께 담당자가 수정 중입니다.
- 지우기 되돌림은 기본으로 숨겨져 있으며 Ctrl Z는 지우기 되돌림 단축키가
  아닙니다.

## 결과를 전달합니다

설치가 실패하면 실패한 명령과 PowerShell 오류를 전달합니다. 화면 문제는 사진이나
짧은 영상, 발생 시각, 복사한 데이터 폴더의 `logs/main.log`를 함께 전달합니다.
성공한 항목도 통과로 적고, 직접 보지 못한 항목은 확인하지 못함으로 적습니다.

```text
태그: m3-check2
확인 날짜와 시작 / 종료 시각:
앱에 표시되는 버전:
전체 결과: 통과 / 실패 / 확인하지 못함
항목: 새 예배 / 준비 / 성경 / 퀵 실행 / 화면 설정 / 출력 / 종료와 재실행
조작: 곡 이름, 슬라이드 번호, 누른 버튼이나 키
예상 동작 / 실제 동작 / 다시 해도 같은지:
Windows 화면 배율과 각 모니터 해상도:
앱 창 크기와 최대화 여부:
UI 확대: Ctrl 0 후 Ctrl +를 누른 횟수 또는 배율
슬라이드 크기 %:
모니터 번호 카드: 위치, 번호, 사라졌는지, 포커스 유지 여부
항상 위: 본 화면과 무대 창을 겹쳤을 때의 차이
닫기와 재실행: 대화상자 제목, 메모 유지, 출력 꺼짐 여부
사진, 영상 또는 로그:
```

[화면과 출력](../spec/03-output.md),
