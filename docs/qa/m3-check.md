# M3 앱 확인 안내

약 40분 동안 확인하는 안내입니다. 실행할 태그는 `m3-check3`이며 커밋은
`9bde04fd`입니다. 앱 버전은 `0.16.0`입니다. 2026년 10월 26일 21시 무렵에 편한
시간에 시작합니다.

## 설치하고 실행합니다

Git과 프로젝트에서 사용하는 Node.js, npm이 설치된 Windows에서 PowerShell을
엽니다. 기존 개발 폴더와 다른 새 폴더를 사용합니다. 샘플은 태그 이후에 작성한
점검 자료에서 따로 가져옵니다. 아래 `git restore`는 점검 자료 경로에만 적용하며
앱 소스는 태그를 유지합니다.

```powershell
git clone --branch m3-check3 --single-branch https://github.com/0913vision/llpresenter llpresenter-m3-check3
Set-Location -LiteralPath .\llpresenter-m3-check3
git fetch --no-tags origin docs/qa/m3-check
git restore --source=FETCH_HEAD --worktree -- docs/qa/m3-check
npm ci

$sampleData = Join-Path $env:LOCALAPPDATA 'LoveLight-m3-check3'
if (Test-Path -LiteralPath $sampleData) {
  throw '이미 있는 데이터 폴더입니다. 새 폴더 이름을 지정합니다.'
}
Copy-Item -LiteralPath .\docs\qa\m3-check\sample -Destination $sampleData -Recurse
$env:LLP_USER_DATA = $sampleData
```

`app.json`, `bible`, `LoveLight`가 함께 있는 복사본 폴더를 지정합니다. 샘플
원본을 직접 지정하지 않습니다. 로그와 백업은 복사본에 생깁니다.

실제 두 번째 모니터에서 전체 화면을 확인하려면 앱 실행 전에 다음 선택 명령을
실행합니다. 창을 열지 않는 점검 도우미가 주 모니터가 아닌 첫 모니터를 본 화면에
배정하고, 전체 화면과 항상 위 설정을 켭니다. 콘솔의 기기 이름을 확인합니다.
모니터가 하나이면 설정을 바꾸지 않으며 전체 화면 항목은 확인하지 못함으로
남깁니다. 이 명령을 생략하면 본 화면과 무대 화면은 별도 창으로 열립니다.

```powershell
node --check .\docs\qa\m3-check\prepare-display.cjs
if ($LASTEXITCODE -ne 0) { throw '점검 도우미 구문 검사에 실패했습니다.' }
$env:LLP_TEST_WINDOWS = 'offscreen'
& .\node_modules\electron\dist\electron.exe .\docs\qa\m3-check\prepare-display.cjs | Out-Host
if ($LASTEXITCODE -ne 0) { throw '모니터 배정에 실패했습니다.' }
Remove-Item Env:LLP_TEST_WINDOWS
```

이어서 같은 PowerShell에서 빌드하고 실행합니다. 다시 실행할 때도 이 창에서
`npm run preview`를 실행해야 같은 데이터 폴더를 사용합니다.

```powershell
npm run build
npm run preview
```

성경 점검 자료는 **실제 성경 본문이 아닙니다**. 역본 이름과 모든 문장에 창작
점검 자료라고 표시했으며, 요한복음의 위치만 들어 있습니다. `요 3:16-18`처럼 주소
입력과 출력 동작을 확인합니다. 찬양 가사도 모두 점검용 창작문입니다.

## 종료 문제와 현재 제한을 확인합니다

- M3-C2-1은 이번 태그에서 수정됐습니다. QA가 출력을 켰다 끈 뒤 정상 종료를 두 번
  확인했고, 앱 프로세스와 출력 창이 모두 종료됐습니다. 작업 관리자에서 강제
  종료하는 절차는 필요하지 않았습니다.
- M3-C1-1은 이번 태그에서 수정됐고 파일 잠금과 재시도를 QA가 확인했습니다.
  사용자는 파일 잠금 종료 시험을 하지 않습니다. 예상치 못한 `저장할 수 없음`이
  보이면 내용을 기록하고 다시 시도합니다. 저장되지 않은 편집을 버리는
  `강제로 닫기`는 점검에 사용하지 않습니다.
- `저장 중` 대화상자는 빠른 저장에서는 나타나지 않습니다. 보이지 않았으면
  확인하지 못함으로 적습니다. 실제 두 번째 화면, 번호 카드의 포커스와 전체
  화면의 항상 위 상태도 사용자 확인 항목입니다.
- 텍스트로 곡 가져오기는 대화상자 코드가 있으나 여는 메뉴가 연결되지 않아 이번
  태그에서는 사용할 수 없습니다.
- 무대 배치 편집기는 아직 사용할 수 없습니다. 기존 무대 배치와 타이머 선택을
  확인합니다. 화면 속성 패널은 사용할 수 있지만 모니터 배정 제어는 아직
  없습니다. 실제 두 번째 화면 배정에는 위의 선택 도우미를 사용합니다.
- 오디오는 숨겨진 창이 추가됐으나 아직 소리가 나지 않습니다. 검은 화면 퀵 실행과
  성경의 추가 표시 설정도 아직 제한됩니다. 이번 성경 샘플은 창작 점검 문장만
  사용합니다.
- 준비에서 추가한 성경 항목의 전용 편집과 진행 출력 연결에는 아직 미완성 부분이
  있습니다. 성경 출력은 위 표의 진행 주소 칸과 저장된 퀵 실행으로 확인합니다.
- 지우기 되돌림은 기본으로 숨겨져 있으며 Ctrl Z는 지우기 되돌림 단축키가
  아닙니다.
