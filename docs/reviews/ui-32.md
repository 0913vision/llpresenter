## What changed and why

Selecting a song item in the 준비 예배 순서 now shows it in the center column,
built from the ui-31 store. The design system wins over the `PrepService` board.

- **Header** (`Panel` title header): the song title with `슬라이드 9개` as the
  count, and `라이브러리 곡 편집` (`Button` secondary sm, `edit` icon), which
  opens the song in the editor; the columns then switch to the editor's.
- **구성 row:** the `구성` name and a `SelectMenu` (sm) with 기본 and the song's
  구성. Choosing one changes only this item. A read-only service disables it
  with the reason in its tooltip. 새 구성 comes in ui-33.
- **Chip strip** (`ArrangementStrip`): one chip per position of the effective
  구성. The arrows select, and a chip selects the matching thumbnail and back.
  Alt ← and Alt → move the selected chip one place and Delete removes the
  position, both through the song's session (ui-31), so the order changes in the
  song file. 슬라이드 넣기 opens a menu of the song's 슬라이드 (이름표 swatch,
  이름표 or number, and the first line) and appends the chosen one. The chip of
  the live position has the live ring. With 기본 (or a read-only song) the strip
  is read-only, with the reason in the tooltips.
- **Undo:** Ctrl Z, Ctrl Y, and Ctrl Shift Z in the panel undo and redo the
  song's history (lead decision; one history per song, shared with the editor).
  `historyCommand()` is extracted from the editor's key map, which now uses it
  too.
- **Thumbnails:** the editor's `VirtualSlides` in playback order (an empty 구성
  shows file order, as in 진행), with the shared thumbnail size control in the
  footer. Clicking only selects; nothing goes to the output.

`ArrangementStrip` gained the read-only state the panel needs: `readOnlyReason`
makes the listbox `aria-readonly`, keeps selection, ignores (and consumes) Alt
arrows and Delete, disables the insert button, and shows the reason in the chip
and insert tooltips. The LabelChip README and the gallery show it.

## Decisions I made (for the lead to confirm)

- The board's service name chip in the header (`주일 예배`) is left out: the
  design system's title header has a title and a count only, and the 예배 순서
  panel already shows the service name.
- The insert menu labels a 슬라이드 as its 이름표 (or number) and its first line
  in one label, with the 이름표 swatch; the menu's trailing text is for dates
  and shortcuts only.
- Removing the last chip leaves an empty 구성, which plays file order (spec 02);
  the strip then shows no chips and only the insert button.
- Reasons: `기본 구성은 변경할 수 없습니다` (as in the editor's 구성 row) and
  `새 버전의 파일이라 바꿀 수 없습니다` for a read-only song or service.
