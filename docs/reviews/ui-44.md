## What changed and why

Adds `TextImportDialog`, using the existing read/preview contract and design
system Dialog, fields, menus, checkbox, and slide thumbnails. It exposes split
mode, units per slide, label recognition, and a symbol field. Options rebuild
the preview through main; an edited title stays intact across rebuilds.
Duplicate titles show the existing field error and reason. Edit hands an unsaved
draft to the host; Discard, close, and Escape discard it. There is no save here.

Preview requests run one at a time with only the newest pending options. Old
responses and responses after unmount cannot replace current content. Errors are
reported through the host's notice callback. The existing `VirtualSlides` keeps
large previews bounded and keyboard reachable; it now accepts only the slides it
actually reads instead of requiring a persisted song identity.

The imported editor and File-menu mounting are the next P5 request. This unit
provides the dialog independently so that each review stays small.
