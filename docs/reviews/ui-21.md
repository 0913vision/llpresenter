## What changed and why

This is the first part of the P2a split authorized by the lead. It adds the
immutable block operations and song history that the editor view will use. The
view, keyboard dispatch, save connection, and 이름표 menu follow in the next
request. P2a is not complete with this model request alone.

`editBlocks` handles ordinary Enter, splitting on an empty or whitespace-only
line, Ctrl Enter splitting at the cursor or a selection, inserting an empty
block, merging at block start, plain-text paste with blank paragraphs, and label
assignment. It returns the edited shared `Song` and a bounded UTF-16 selection
for the next textarea. CRLF input normalizes to LF. The source song remains
unchanged.

Every structural edit remaps all named arrangement references under the lead's
split/merge decision in `docs/decisions.md`. A split expands each reference to
all parts in order: splitting slide 3 changes `[1, 3, 3]` to `[1, 3, 4, 3, 4]`.
A merge maps both source references to the result, collapsing adjacent pairs of
different merge sources. Deliberate repeats remain: `[2, 3, 2, 3]` becomes
`[2, 2]`, and `[3, 3]` becomes `[2, 2]` when 3 merges into 2. Empty arrangements
remain present. Unaffected blocks retain their object identity, and text/label
edits retain arrangement objects. Object spreads keep existing song, block, and
arrangement extensions.

`SongHistory` owns one song's session history, with at most 100 undo steps.
Typing coalesces within the same block until a full second passes without input.
Block changes, blur, structural edits, and a backwards clock end the group.
Undo/redo restore the song and selection; a new edit clears redo. The future
view owner retains each song's instance when switching songs. There is no global
history cache, timer, listener, IPC, or persistence in this model.

## Decisions I made

- A split retains the first block's label and identity, with new parts
  unlabeled. Every named-arrangement reference expands to all parts, following
  the lead's decision after round 1.
- Merge keeps the previous block's label and concatenates line arrays. It maps
  the removed block's references to the result. Adjacent distinct source pairs
  collapse once, preserving intentional repeats and repeated split/merge cycles.
- History uses an injectable edit timestamp and explicit blur boundary, so it
  needs no idle timer. The next view must call `endTyping` when focus leaves.
