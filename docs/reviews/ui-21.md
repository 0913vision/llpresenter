## What changed and why

This is the first part of the P2a split authorized by the lead's approximately
600-line limit: 569 source and test lines. It adds the immutable block
operations and song history that the editor view will use. The view, keyboard
dispatch, save connection, and 이름표 menu follow in the next request. P2a is
not complete with this model request alone.

`editBlocks` handles ordinary Enter, splitting on an empty or whitespace-only
line, splitting a selection, inserting an empty block, merging at block start,
plain-text paste with blank paragraphs, and label assignment. It returns the
edited shared `Song` and a bounded UTF-16 selection for the next textarea. CRLF
input normalizes to LF. The source song remains unchanged.

Every structural edit remaps all named arrangement references, including
repeated numbers and empty arrangements. For example, splitting slide 1 changes
`[3, 2, 1, 2]` to `[4, 3, 1, 3]`. Unaffected blocks retain their object
identity. Text and label edits retain arrangement objects. Object spreads keep
existing song, block, and arrangement extensions.

`SongHistory` owns one song's session history, with at most 100 undo steps.
Typing coalesces within the same block until a full second passes without input.
Block changes, blur, structural edits, and a backwards clock end the group.
Undo/redo restore the song and selection; a new edit clears redo. The future
view owner retains each song's instance when switching songs. There is no global
history cache, timer, listener, IPC, or persistence in this model.

## Decisions I made

- A split retains the first block's label and identity. New parts are unlabeled;
  custom arrangements keep their existing references rather than automatically
  adding the new parts. Later slide numbers shift as spec 02 requires.
- Merge keeps the previous block's label, concatenates the line arrays, and
  drops the removed block's references. Empty named arrangements stay present.
- History uses an injectable edit timestamp and explicit blur boundary, so it
  needs no idle timer. The next view must call `endTyping` when focus leaves.
