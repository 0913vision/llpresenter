## What changed and why

Adds the additive `textImport.clipboardAvailable()` query and a checked boolean
reply. Main checks for nonblank clipboard text within the existing import
character cap and returns only availability. It coalesces concurrent checks,
does not reserve the file-read gate, logs failures, and drops late availability
after registration cleanup. Preload logs and rejects malformed or failed
replies.

The File menu checks availability when opened, disables clipboard import while
checking or unavailable, and refreshes on reopening. At most one menu query runs
at once across rapid reopenings. Unmount releases the effect and ignores pending
results. Clicking a ready item still rereads the current source through the
normal import flow, so the query never substitutes stale content for the import.

The source-read command remains unchanged. A separate query is necessary because
using that command for menu availability would contend with its single pending
file/clipboard read and unnecessarily return clipboard text to the renderer.
