## What changed and why

The imported editor reuses the normal song editor, whose lyric list previously
mounted a textarea and label picker for every slide. The list now mounts only
the visible range with two rows of overscan. It calculates row offsets from line
counts, the resolved textarea line height, padding/border metrics, and the
existing label-size token. One viewport observer refreshes the measurements and
is disconnected on unmount. Short unmeasured lists retain their full rendering.

The selected row and open label-menu row stay mounted outside the range. This
preserves input composition and popup anchors while scrolling. Keyboard arrows,
editing commands, and history still restore the lyric cursor. Tab and Shift-Tab
follow logical row order across virtual windows, including read-only rows that
have no label picker. A selection from another panel reveals the selected row.

Rows retain memoization by receiving a numeric position rather than a new style
object from the parent on every edit. Input references are trimmed after slide
deletions. This request changes neither song persistence nor the undo model.
