## What changed and why

`new Date().toTimeString().slice(0, 5)` was copied eleven times in ten renderer
files to write the HH:MM time of a notification card. `ui/notices` now exports
`noticeTime(now = new Date())`, next to the `Notice` type whose `time` field it
fills, and every copy calls it. The behavior is unchanged.

The ui-29 nit: the jump key field's reason in `LabelDialog.tsx` was still the
noun phrase `영문자 또는 숫자 키`. It is now the named sentence
`JUMP_KEY_REASON` (`영문자나 숫자 키만 쓸 수 있습니다`), like the other editor
reasons.
