## What changed and why

Two `ListBox` problems from codex2's review of shell-16.

1. **Every row redrew on a selection change.** `ListBox` kept `selected` in its
   context, so a new selection redrew every row, against the rule to redraw only
   what changed. Now `ListBox` keeps the selected value in a small store, and
   each `ListRow` reads only whether it is the selected one
   (`useSyncExternalStore` with a boolean selector), so only the old and the new
   selected row redraw. `ListRow` is `memo`, and the context value stays the
   same object across selections (the latest `onSelect` sits in a ref), so a
   parent that redraws the list doesn't redraw unchanged rows. The live mark is
   a `ListRow` prop, not context, so it redraws only the rows whose `live`
   changed.
2. **Shift Tab was trapped before any selection.** With nothing selected, the
   list itself was tabbable and passed focus to its first row, so Shift Tab from
   that row landed on the list and came back. Now the list never takes focus: it
   gives the Tab stop to the selected row, or to the first enabled row with none
   selected, on the DOM (as `TileList` does), so Tab enters once and Shift Tab
   leaves. In round 2, one observer per list also updates it when a descendant
   changes rows without rendering `ListBox`. A selection store subscription
   updates the Tab stop on selection changes. Both are released when the list
   unmounts.

`ThumbnailGrid` already works this way (memo tiles with `selected` as a prop,
the Tab stop on the DOM); a render-count test now shows it. Its TSDoc still said
the grid takes the Tab stop while nothing is selected, which was wrong; it says
the first thumbnail takes it.

## Team member's reply

1. The Tab stop depended on `ListBox` rendering, so removing its first row from
   a stateful descendant left the remaining rows at `tabIndex=-1` when nothing
   was selected. The list now observes descendant child changes and
   `aria-disabled` and `data-value` changes, and recomputes the Tab stop using
   the current selection store value. Tab index writes are excluded from the
   observer's attribute filter. The observer and store subscription stay in
   place across renders and are both released on unmount. This updates the DOM
   without adding row renders. Four regression cases keep state in a descendant
   of `ListBox`: removing, disabling, enabling, or inserting the first row. Each
   checks Tab entry, a single enabled Tab stop, Shift Tab exit, and no selection
   callback. All four fail on the round 1 code.
