## What changed and why

`WindowedMediaStrip` mounts only the visible part of a long 진행 media strip. It
named each mounted tile's place in the full list by writing `aria-orientation`,
`aria-setsize`, and `aria-posinset` into the DOM that `MediaStrip` and
`TileList` own, after every render. ui-28 gave `TileList` position props for
that; this request finishes the task: `MediaStrip` takes `positionOffset`,
`setSize`, and `orientation` and passes them to `TileList`, and
`WindowedMediaStrip` passes them instead of writing attributes. The attributes
are the same as before (its existing test checks them), and the host no longer
touches ui-owned nodes.
