service name was easy to miss, and UI text was too small. This request contains
the alternatives shown to the user, ten PNG exports, an offscreen render/check
harness, and the choices the lead relayed after the user compared them.

the selected small slot and the large picture above. It uses three preview
renderings. The selected service header is A: the service name replaces the
generic label at 34px height, in 16/22 semibold. The user selected the proposed

smaller than 12px. The clear undo button setting defaults to off.

## Team member's reply

1. The top-level assertion could throw before the promise error handler and
   trigger Electron's visible error dialog when `LLP_TEST_WINDOWS` was missing
   or incorrect. The entry now writes the required setting to stderr, calls
   `app.exit(1)`, and returns before readiness, timers, or rendering are
   scheduled. `render.test.cjs` executes the actual CommonJS entry with a fake
   Electron API. Missing, empty, `off`, and `OFFSCREEN` values must not throw,
   must request exit code 1, and must not schedule a timer, readiness handler,
   or window. The valid `offscreen` case still waits for readiness. All four
   rejection cases fail on the round 1 assertion. No invalid-flag Electron
   process is launched by these tests.
