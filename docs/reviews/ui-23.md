## What changed and why

When main replied quickly, typing eight characters sent eight whole-song edits
and broadcasts, including to output windows. Text and ordinary Enter now wait
for a typing-group boundary: block/song change, blur, or 1 second without input.
The idle interval and typing classification come from `SongHistory`, so the save
boundary agrees with the existing undo grouping. Structural commands and
undo/redo still save immediately.

Each session has one timer, one write in flight, and its newest dirty draft. A
previous write's reply does not flush a newer group before its boundary. If the
boundary expires while a write is in flight, the newest draft waits for that
reply and uses its accepted revision. Explicit `flush()` and shutdown cancel the
timer and drain accepted input, including new input queued during a write.
Reload, deletion, refusal, and disposal release deferred timers.

External pushes during the new deferred-save interval are buffered while a draft
is dirty. They cannot replace unsaved lyrics. Checked revisions still refuse a
stale save, preserving the draft and the existing reload action. Global rename
continues to flush cached edits before invoking main.
