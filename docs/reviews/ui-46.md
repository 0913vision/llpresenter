## What changed and why

File > Import now opens a text file or clipboard text. The host starts Prep,
reads current import preferences and the source once, and mounts the options
dialog. Edit opens the imported song in the existing editor; nothing is saved
yet. StrictMode cannot open a second file picker. Cancelled reads stay silent,
failed reads produce a notice, and late replies cannot reopen a closed flow.

An imported editor hides the library/source tags and adds Discard and Save.
Empty titles disable Save with the existing reason. A new title saves directly
and selects the accepted song in the library. An existing title opens the
design-system confirmation with the target's slide count and modification date.
Cancel/Escape keeps the draft, Save as new chooses the next unused numbered
title, and Overwrite/Enter sends the fetched document's revision. Read-only
targets disable overwrite while permitting a new copy. Failed target reads
retain the draft and produce a notice.

Leaving an imported editor mounts the store's discard confirmation. The host
also guards starting another import or opening a Prep item. Header and dialog
actions lock while a save or target read runs.

This request uses the existing source-read contract. Empty clipboard text is
reported by that read; the contract has no separate availability query to
disable the clipboard menu before reading it. That proposal and windowing the
existing lyric editor for large imports are follow-up P5 work.
