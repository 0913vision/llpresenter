## What changed and why

Adds a manual persistence mode to the existing song session. Imported titles,
lyrics, backgrounds, undo/redo, and arrangements use the existing editor model
without autosaving. Empty and duplicate title drafts survive blur. The store
retains one imported session outside the library session cache, so document
feeds cannot remove it or add its synthetic identity to the library.

Navigation or another import requests discard confirmation without replacing the
current draft. Cancel keeps it; confirmed discard releases it and executes the
pending action. An unsaved import refuses the existing close flush.

Explicit Save uses `song.import` with the chosen new or overwrite target and
then opens main's accepted document as a normal autosaving session. A refused
write keeps the draft. Applied disk failures keep the accepted document and
report the warning. If only reading that document fails, the draft becomes
read-only and a subsequent Save retries the read without importing twice. Edits
and duplicate operations stay locked while Save runs.

This unit supplies the editor state and persistence. The next unit adds the
header controls, confirmation dialogs, and File-menu mounting.
