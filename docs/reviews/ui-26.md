## What changed and why

The song header now mounts the approved background picker. Selecting an image,
video, or none saves through the existing coalesced song queue. The Select shows
the media name and a 36x20 lead, with videos muted and paused. Choosing or
pressing Escape returns keyboard focus to the trigger.

The mounted control subscribes to media changes. A newer push wins over a
delayed startup reply or failure. Loading, retry, missing references, read-only
songs, and global label operations have explicit states. Locking closes an open
picker without reopening it on unlock. Media catalog read-only access does not
block selecting a background for an editable song. Catalog removal preserves the
song's ID until the user chooses a replacement or none.

The header keeps its 34px single-row height and wraps at narrow widths. The
ui-25 nit is resolved by removing unreachable Home/End navigation cases. Those
keys edit the search caret; Up from none wraps to the last eligible result.

This request completes the background header slice. 구성, preview, and the slide
list remain the next small P2b requests to keep this change near the 600-line
limit. The approved title/tags/model/picker work is reused.
