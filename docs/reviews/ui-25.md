## What changed and why

Titles now use trim plus NFC before duplicate checks and persistence. Library
titles use the same identity, covering older decomposed/whitespace records.
Acknowledgments compare the captured raw input, so a reply cannot erase a newly
typed space. Invalid drafts stay visible while lyrics save canonically.

This request adds the background editing model and selection primitives.
`setBackground` shares the song's one-write queue, retains newer choices behind
an in-flight response, preserves accepted metadata through lyric undo, and
removes the optional field for none. Deletion cancels a queued choice.

`MediaPicker` virtualizes the image/video list, with none, logical arrow/Home/
End/typeahead navigation, and `aria-activedescendant`. It mounts at most twelve
options even for thousands of items. A Select video lead stays muted/paused,
loads metadata, and unloads on source change/unmount.

The header control and media subscription are kept in the following ui-26 branch
to preserve the roughly 600-line split. Background selection is not yet mounted
in the editor. 구성 and preview/list remain later P2b requests.
