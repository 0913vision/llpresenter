## What changed and why

A label press whose mouseup occurs inside the label keeps pending focus until
the forwarded click. The existing keydown cleanup ran only in Show's bubbling
handler. When a field or a window capture handler swallowed the key first, that
cleanup never ran. A later keyboard focus on the control could be restored to
the previous owner once.

Show now also clears pending click state in a window keydown capture listener,
before fields and parent handlers consume the event. It reuses the existing
cleanup function and removes the listener with the same capture option on
unmount. Normal forwarded label clicks keep their existing focus behavior.

The lead renewed the ui-19 exception for these two shell-owned files only.

## Decisions I made

Use keydown capture instead of clearing on unrelated focus. It resets the press
before keyboard handlers can stop bubbling and retains the current label focus
restoration path.
